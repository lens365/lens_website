https://leetcode.cn/problems/maximum-beauty-of-an-array-after-applying-operation/description/
这道题本质是想要获取最大的区间重叠次数
对于这道题，我们就会想要用差分数组来处理，这样可以无需双指针所需要的排序过程
差分的意义就是后一个对前一个的差
这样可以很好的解决需要循环遍历的问题
```
class Solution:
    def maximumBeauty(self, nums: List[int], k: int) -> int:
        m = max(nums)
        diff = [0] * (m + 2)
        for x in nums:
            diff[max(x - k, 0)] += 1
            diff[min(x + k + 1, m + 1)] -= 1
        res, count = 0, 0
        for x in diff:
            count += x
            res = max(res, count)
        return res
```
